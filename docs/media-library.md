# Wine With Pete Media Library

## Purpose

Wine With Pete should document the life it is actually creating. The media library is the durable source archive for tables, food, fire, people, menus, objects, and future editorial work.

The website should use optimized exports. Originals should live in durable cloud storage with a second backup rather than inside the code repository.

## Naming convention

Use:

`YYYY-MM-DD_event_subject_sequence.ext`

Examples:

- `2026-05-23_giscours_table-wide_001.jpg`
- `2026-05-23_giscours_wine-pour_002.jpg`
- `2026-06-27_seoul-bowl_overhead_001.jpg`

Do not rely on camera filenames as the only identifier.

## What every meaningful table should capture

### Before guests arrive

- one clean wide image of the room or table
- place settings
- menu / printed material
- bottles
- ingredients
- fire or cooking setup
- location / exterior when useful

### During

- one wide image with people around the table
- Pete in action
- two natural human interactions
- hands passing or serving food
- wine or another beverage being poured
- cooking / flame / process
- the table midway through dinner
- one finished food hero

### After

- table remnants
- empty glasses / plates
- fire dying down
- finished menu / ephemera
- one quiet closing image

## Ten-shot minimum

If time is limited, leave every table with at least:

1. hero horizontal
2. people-wide
3. people-detail
4. Pete-in-action
5. food hero
6. serving / hands
7. wine pour
8. fire / process
9. menu / object detail
10. after-the-table image

## Editorial workflow

After each table:

1. Back up originals immediately.
2. Create a Selects folder; never delete originals during curation.
3. Choose 10–25 images that tell a sequence rather than only showing beautiful food.
4. Record the menu, date, place, purpose, wines when relevant, one memorable moment, and a short reflection.
5. Create web exports only after the editorial sequence is chosen.
6. Add the best cross-event images to Brand Selects without removing them from their original table folder.

## Website export rules

- WebP or AVIF where practical
- preserve originals separately
- avoid uploading multi-megabyte originals directly to the repository
- create distinct horizontal and mobile crops when the composition needs them
- prioritize authentic human/documentary images over generic or generated imagery in proof sections
- generated illustration may support essays or editorial concepts, but should not stand in for documentary proof of a real table

## Table Archive standard

A mature Table Archive story can contain:

- title
- date and place
- 5–12 photographs
- short concept / reason for the table
- menu
- wine when relevant
- one or two design choices that shaped the evening
- reflection / what the table taught us
- related recipe, essay, guide, or object when genuinely connected

Not every table needs all of these. The archive should remain truthful and sparse rather than padded.

## Backup rule

Any professionally photographed Wine With Pete event should be copied into Wine With Pete-owned storage as soon as the gallery is delivered. A photographer's shared Drive or gallery is a transfer mechanism, not the permanent archive.
